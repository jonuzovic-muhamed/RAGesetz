# RAGesetz — Retrieval-Augmented Generation for German Laws

## About

RAGesetz is a Spring Boot application that aims to correctly and with reffernce to actuall paragraphs answers legal questions about German Law.

It automatically retrieves the most relevant legal paragraphs from a vector database and feeds them into a **local LLM (via [Ollama](https://ollama.ai))** together with the users question/s in order to produce grounded, context-aware responses.

It is a project I did for class in school.
